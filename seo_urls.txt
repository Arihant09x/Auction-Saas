======================================================================
AUCTION SAAS SYSTEM - ROUTE INDEX & SEO CRAWL MAP
======================================================================

Below is the list of all URLs generated by both the Landing Page Web Application
(apps/web) and the Organizer Dashboard Application (apps/dashboard).

This map indicates which routes should be indexed by search engines (Google, 
Bing, etc.) to maximize SEO visibility, and which routes must be kept private
or blocked via robots.txt to protect data and user accounts.

----------------------------------------------------------------------
1. LANDING PAGE WEBSITE (apps/web)
   Target Hostname: e.g., https://bidarena.io
----------------------------------------------------------------------
[INDEXED / ALLOWED]
- /                        - Landing Page Home
- /about                   - Company / Product Details
- /pricing                 - Subscription & Purse Limits
- /blogs                   - Sports News & Updates
- /today-auction           - List of Live/Active Auctions today
- /upcoming-auction        - List of Upcoming Auctions
- /terms-and-conditions    - Terms of Service Agreement
- /privacy-policy          - User Privacy Policy
- /cancellation-policy     - Refund & Cancellation terms
- /shipping-policy         - Physical Item Shipping Policy

[BLOCKED / DISALLOWED]
- /login                   - Sign-In / Account Access Portal
- /auth/sync               - Token Sync Handler
- /manifest.json           - App Metadata Schema
- /icon0.svg / icon1.png   - Vector assets

----------------------------------------------------------------------
2. ORGANIZER DASHBOARD APPLICATION (apps/dashboard)
   Target Hostname: e.g., https://app.bidarena.io
----------------------------------------------------------------------
[BLOCKED / DISALLOWED ENTIRELY]
- /dashboard/organizer                - Main User Console
- /dashboard/my-auction                - List of Created Auctions
- /dashboard/create-auction           - Wizard to Setup New Auction
- /dashboard/join-auction             - Search & Register for Auctions
- /dashboard/manage/[auctionId]/details   - Control Room for Specific Auction
- /dashboard/manage/[auctionId]/teams     - Franchise & Purse Manager
- /dashboard/manage/[auctionId]/players   - Player Pool Upload (Manual/Bulk)
- /dashboard/manage/[auctionId]/categories- Category Override Settings
- /dashboard/manage/[auctionId]/customize - Live Sold Sound/Animations Config
- /dashboard/manage/[auctionId]/payment   - License Purchasing / Ledger
- /dashboard/manage/[auctionId]/edit      - Auction Profile Editor
- /dashboard/auctions/panel           - System Command Center
- /live/[auctionId]                   - Real-time Bid Controller
- /viewer/[auctionId]                 - Viewer Tracker Dashboard
- /overlay/[auctionId]                 - OBS Live Video Overlay Screen
- /admin                              - Master Site Admin View
- /auth/sync                          - Session Authenticator

======================================================================
RECOMMENDATION: Put sitemap.xml on the landing page root directory to
point to the allowed public routes listed in Section 1.
