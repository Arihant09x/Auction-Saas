## 4 for redis setup
 create an network for api to access the redis
 docker network create app-network

 and run the redis container 
 docker run -d --name redis --network app-network redis

 and also run the api with this cmd
 docker run -d -p 3000:3000 --name my-api-app --network app-network --env-file api.env my-api-app
